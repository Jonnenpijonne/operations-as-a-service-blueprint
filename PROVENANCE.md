# Provenance

This repository contains the operations and governance material authored by Jonne Silvennoinen during earlier portfolio work in `Jonnenpijonne/OaaS`.

That earlier repository was technically a fork of the unrelated `hpcclab/OaaS` / Object-as-a-Service platform.

This clean repository intentionally excludes:

- upstream Java source code
- upstream Object-as-a-Service implementation
- Maven/platform build configuration
- upstream Git history
- unrelated platform automation

The retained material focuses only on the authored Operations-as-a-Service blueprint:

- service and operating models
- responsibility boundaries
- incident and escalation models
- controlled change
- backup and recovery
- SLA/SLO thinking
- evidence design
- public/private boundaries
- handover and review templates
- public-safe examples

The original fork remains available separately for historical traceability.
